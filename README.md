# Струны будущего

Сайт онлайн-школы Никиты Осадчука. Next.js / React, статический экспорт для GitHub Pages.

## Запуск

```bash
npm ci
npm run dev
```

## Публикация

```bash
npm run build:pages
```

Готовые файлы находятся в `out/`. Существующий workflow `.github/workflows/deploy-pages.yml` публикует ветку `main` на https://strunibb.github.io/struny-school/.

## Содержимое

- `app/page.js` — секции, инструменты, цены, FAQ, диалоги записи и видео.
- `app/program-data.js` — этапы программы и репертуар.
- `app/globals.css` — оформление и адаптивная вёрстка.
- `public/` — фотографии, памятка ученика и расписание.

Запись открывает готовый текст в Telegram; посетитель отправляет его самостоятельно. Также доступна существующая онлайн-запись Yclients. Персональные данные на сервер сайта не отправляются.

Отзывы ведут в реальный профиль на Профи.ру. Видео учеников запрашиваются в Telegram: в исходных материалах не было прямых ссылок для встраивания. Бесплатный вводный видеоурок можно запросить в Telegram. Прежняя ссылка VK показывала «Видео недоступно» при проверке, поэтому не используется.
