# Струны будущего

Сайт онлайн-школы Никиты Осадчука. Next.js / React, статический экспорт для GitHub Pages.

## Запуск

```bash
npm ci
npm run dev
```

## Публикация

```bash
npm run build:pages
```

Готовые файлы находятся в `out/`. Существующий workflow `.github/workflows/deploy-pages.yml` публикует ветку `main` на https://strunibb.github.io/struny-school/.

## Отдельный хостинг

```bash
SITE_URL=https://example.ru npm run build:static
```

Замените `example.ru` на свой домен и загрузите содержимое `out/` в корень сайта. Node.js на сервере не нужен. GitHub Pages использует прежнюю команду `build:pages` с префиксом `/struny-school`.

## Форматы обучения

- Гитара: полный курс 5 990 ₽ (год доступа), тот же курс с проверкой 9 990 ₽ (год доступа, шесть месяцев проверки), «2+2» 2 990 ₽, личные занятия 3 990 ₽.
- Электрогитара, укулеле, фортепиано: четыре личных занятия по 40 минут за 3 990 ₽.
- «2+2»: два личных урока по 40 минут и две недели готовых видеозаданий с проверкой; полный курс приобретается отдельно.
- Каталог песен связан с главным сайтом навигацией, цены хранятся отдельно в репозитории `struny-songs`, ветка `gh-pages`.

## Содержимое

- `app/page.js` — секции, инструменты, цены, FAQ, диалоги записи и видео.
- `app/program-data.js` — этапы программы и репертуар.
- `app/globals.css` — общие стили; `app/hub.css` — оформление единой витрины и мобильная адаптация.
- `public/` — фотографии, памятка ученика и расписание.

Запись открывает готовый текст в Telegram; посетитель отправляет его самостоятельно. Также доступна существующая онлайн-запись Yclients. Персональные данные на сервер сайта не отправляются.

Отзывы ведут в реальный профиль на Профи.ру. Видео учеников запрашиваются в Telegram: в исходных материалах не было прямых ссылок для встраивания. Бесплатный вводный видеоурок можно запросить в Telegram. Прежняя ссылка VK показывала «Видео недоступно» при проверке, поэтому не используется.
