# Видео для раздела «Наши кейсы»

Раздел на главной странице содержит пять карточек с горизонтальной прокруткой.

Чтобы добавить видео, загрузите MP4 в эту папку с **точными** именами:

1. `student-01.mp4`
2. `student-02.mp4`
3. `student-03.mp4`
4. `student-04.mp4`
5. `student-05.mp4`

Сайт автоматически подхватит каждый ролик без изменения кода: вместо заглушки появится превью с кнопкой воспроизведения. По кнопке откроется крупный проигрыватель со звуком и управлением.

**Формат:** MP4, видео H.264, звук AAC, рекомендуемое разрешение 1080p или 720p. Для быстрого запуска используйте экспорт с опцией «fast start» (moov atom в начале файла).

Пока файла нет, карточка отображается как заглушка без несуществующего видео.

Если нужно заменить «КЕЙС 01» на имя ученика, отдельно согласуйте публикацию имени и используйте поле заголовка карточки в `app/page.js`. Не загружайте личные видеозаписи без согласия учеников (и законных представителей, если требуется).
